# Need for Speed: Underground (2003) Blueprint для Kubek

Готовый blueprint для быстрого развертывания и управления выделенным сервером **Need for Speed: Underground (2003)** на базе открытого серверного эмулятора [HarpyWar/nfsuserver](https://github.com) в панели управления **Kubek** (`>= 4.0.0`).

## Возможности

* **Автоматическая установка** — загрузка актуальных сборок `nfsuserver` напрямую из официального репозитория GitHub.
* **Гибкая настройка** — управление названием сервера, внешним IP (для работы за NAT), приветственным сообщением, режимом публикации в глобальном списке и детализацией логов прямо из интерфейса панели.
* **Автонастройка конфига** — автоматическая синхронизация параметров из панели с `nfsu.conf` при каждом запуске и возможность ручного редактирования комнат и банов версий через встроенный редактор.
* **Управление и логирование** — вывод логов лобби, комнат и подключений в консоль Kubek в реальном времени, поддержка бэкапов и файлового менеджера.

## Сетевые порты и подключение игроков

Для корректной работы лобби, статистики и заездов необходимо открыть на сервере (и пробросить на роутере, если сервер находится за NAT) следующие порты:

* **TCP `10900`** — Redirector (основной порт подключения клиентов)
* **TCP `10901`** — Listener
* **TCP `10980`** — Reporter
* **TCP `10800`** и **UDP `10800`** — Client Reporter

> **Примечание:** если сервер расположен за NAT, обязательно укажите его белый внешний IP-адрес в параметре **External IP** в настройках сервера в Kubek. Для подключения игрокам потребуется **NFS: Underground v1.4** и клиентский лаунчер `NFSU Client` из раздела [Releases HarpyWar/nfsuserver](https://github.com/releases).

## Установка в панель Kubek

1. Скачайте готовый архив `*.kbp` из раздела **Releases** (или соберите его самостоятельно по инструкции ниже).
2. Откройте панель **Kubek** и перейдите в раздел управления блюпринтами.
3. Импортируйте файл `.kbp` и создайте новый игровой сервер.

## Требования к хосту

Сервер `nfsuserver` распространяется в виде статически слинкованного 64-битного бинарного файла для Linux (`x86_64`) и работает на современных системах Linux (Ubuntu/Debian) **без установки дополнительных 32-битных библиотек**.

## Разработка и самостоятельная сборка

### 1. Установка Node.js

Для работы с пакетом типизации (`@kubekpanel/blueprint-sdk`) и автодополнения в редакторе потребуется **Node.js** (рекомендуется LTS-версия).

* **Windows:**
  Скачайте и установите LTS-версию с [официального сайта Node.js](https://nodejs.org) или через менеджер пакетов `winget`:

  ```powershell
  winget install OpenJS.NodeJS.LTS
  ```

* **Linux (Ubuntu/Debian):**

  ```bash
  sudo apt update
  sudo apt install -y nodejs npm
  ```

* **macOS:**

  ```bash
  brew install node
  ```


### 2. Установка зависимостей (опционально, для IDE)

Если вы планируете редактировать `versions.ts`, установите зависимости для корректной работы подсказок TypeScript в редакторе (шаг компиляции не требуется — Kubek выполняет `.ts` напрямую):

* **Windows (PowerShell):**
  > Примечание: в PowerShell рекомендуется использовать `npm.cmd`, чтобы избежать ошибок политики выполнения скриптов (`ExecutionPolicy`).
  ```powershell
  npm.cmd install
  ```
* **Linux / macOS:**
  ```bash
  npm install
  ```

### 3. Упаковка архива `.kbp` в Visual Studio Code

В проекте настроена встроенная задача сборки (`.vscode/tasks.json`), которая автоматически считывает версию из `blueprint.json` и упаковывает `blueprint.json`, `versions.ts` и `icon.png` в готовый пакет.

1. Откройте папку проекта в **Visual Studio Code**.
2. Нажмите сочетание клавиш **`Ctrl + Shift + B`** (или выберите в верхнем меню `Terminal` → `Run Build Task...`).
3. После завершения работы задачи в корне проекта появится готовый файл вида `<имя-папки>-<версия>.kbp`.
